# Association Tunisienne Bénévolat

Application web progressive destinée à digitaliser la gestion d'une association de bénévolat.


# Fonctionnalités

- Gestion adhérents
- Formulaire d'inscription complet
- Gestion événements
- Inscriptions activités
- Gestion des sponsors
- Dashboard administration
- Français / العربية


# Stack

Frontend :

- React
- TypeScript
- Tailwind CSS


Backend :

- Vercel Functions
- TypeScript


Database :

- Supabase PostgreSQL


Auth :

- Supabase Auth


Storage :

- Supabase Storage


---

# Installation


## Cloner


```
git clone repository
```


## Installer


```
npm install
```


## Variables environnement


Créer :

```
.env
```


Ajouter :

```
SUPABASE_URL=

SUPABASE_KEY=

DATABASE_URL=
```


---

# Développement


Lancer :

```
npm run dev
```
