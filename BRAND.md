# Identité visuelle de l'application

## Logo

Le logo officiel de l'association est disponible dans :

```
assets/logo.jpeg
```

Claude Code doit analyser cette image avant de créer l'interface.

Le logo doit influencer :

- la palette de couleurs ;
- le style général ;
- les boutons ;
- les cartes ;
- les éléments graphiques ;
- l'écran d'accueil.


Ne pas modifier le logo.

Ne pas changer :

- les proportions ;
- les couleurs originales ;
- la forme.
