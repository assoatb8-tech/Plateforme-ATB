# Association Tunisienne de Bénévolat

## Présentation

Cette application est une plateforme numérique interactive permettant de moderniser la gestion de l'Association Tunisienne de Bénévolat.

Elle permet aux bénévoles de rejoindre facilement les activités de l'association et donne aux responsables les outils nécessaires pour gérer la communauté.

L'application remplace les procédures papier par un système numérique centralisé.

---

# Objectifs

## Objectifs principaux

- Digitaliser les inscriptions des bénévoles.
- Centraliser les informations des adhérents.
- Faciliter l'organisation des événements.
- Automatiser le suivi administratif.
- Améliorer la communication avec les membres.


---

# Public cible


## Les adhérents

Les bénévoles déja existants et ceux qui souhaitent :

- rejoindre l'association ;
- participer aux activités ;
- suivre leur profil ;
- consulter les événements.


## Les administrateurs

Les responsables qui souhaitent :

- gérer les membres ;
- organiser les événements ;
- contrôler les adhésions ;
- suivre les statistiques.


---

# Fonctionnement général


## Création de compte

Un utilisateur peut créer un compte avec :

- email ;
- mot de passe ;
- informations personnelles.


Après inscription, il complète son dossier d'adhésion.


---

# Dossier adhérent

Chaque membre doit remplir un formulaire complet contenant :

Informations personnelles :

- identité ;
- date et lieu de naissance ;
- CIN ;
- adresse ;
- téléphone.


Informations familiales :

- situation familiale ;
- nombre d'enfants ;
- groupe sanguin.


Informations professionnelles :

- profession ;
- employeur ;
- spécialité.


Expérience :

- associations précédentes ;
- sports pratiqués ;
- formations de secourisme.


L'utilisateur confirme l'exactitude des informations fournies.


---

# Gestion des événements


Les administrateurs peuvent :

Créer un événement :

- titre ;
- description ;
- lieu ;
- date ;
- nombre maximum de participants.


Modifier un événement.


Supprimer un événement.


Annuler la participation d'un adhérent.


Les adhérents peuvent :

- consulter les événements disponibles ;
- réserver une place ;
- annuler leur inscription.


---

# Gestion administrative


Les administrateurs disposent d'un tableau de bord permettant :

- voir le nombre d'adhérents ;
- voir les nouveaux inscrits ;
- valider les comptes en attente (statut d'adhésion) ;
- gérer les comptes.


---

# Multilingue


L'application supporte :

## Français

Langue principale administrative.


## العربية

Langue accessible aux utilisateurs arabophones.


L'interface doit automatiquement adapter :

- direction du texte ;
- alignement ;
- menus ;

- chargement rapide ;
- icône application ;
